Slootea is a modern B2B software management platform engineered specifically for beauty centers, medical spas, and wellness facilities to streamline daily operations and client management. Developed in April 2026, the project has been discontinued and the live platform is offline, with the codebase open-sourced on GitHub.

## Key Capabilities

- **Smart Scheduling**: Interactive calendar booking system with automated time slot optimization and client appointment reminders.
- **Client & Inventory CRM**: Centralized customer records, visit histories, real-time product stock tracking, and usage analytics.
- **Business Operations**: Built using Next.js, TypeScript, and PostgreSQL to deliver high performance, data isolation, and low latency for multi-staff facilities.
